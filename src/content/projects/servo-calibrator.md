A calibration tool that runs entirely in the browser using the Web Serial API — no drivers, no install. Point it at a servo with an AS5600 magnetic encoder attached as ground truth, and it walks through finding the servo's real range of motion and installation offset.

Built to remove the guesswork (and repeated re-flashing) from mounting and calibrating servos on the robot arm projects above.

*Repo is currently private while the tool is under active development.*
